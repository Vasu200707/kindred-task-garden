# Kindred Task Garden

What I would like you to do for me is go and build a Kanban board. I would like it to have the following features. I'd like to have a to-do and in progress. First, I'd like you to ask me questions to clarify your understanding, just to make sure we crush the features down. I want the design to be gorgeous and interactive. I would also like to have an integrated Al chatbot that I can ask questions. I want to have the ability to save this information in a database at any time, so I can come back and use it in the future.

I'd like you to build it in the design and use the reference images as your design style.
